# سایت خدمات تأسیساتی

نسخه آماده برای GitHub Pages.

## فایل‌ها

- `index.html`
- `style.css`
- پوشه `assets`

## نکته مهم قبل از انتشار

شماره تلفن، واتساپ، نام مجموعه و آدرس را در فایل `index.html` با اطلاعات واقعی جایگزین کنید.

## انتشار در GitHub Pages

1. فایل‌های داخل این پوشه را در ریشه Repository آپلود کنید.
2. وارد Settings شوید.
3. Pages را باز کنید.
4. در بخش Build and deployment گزینه Deploy from a branch را انتخاب کنید.
5. Branch را روی `main` و Folder را روی `/ (root)` قرار دهید.
6. Save را بزنید.
